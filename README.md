# GrantBridge Europe

Clean application baseline for the Romanian pilot of GrantBridge Europe.

## Status

- Pilot country: Romania
- Planned operator: Szökőcs Green SRL, Sălaj County
- Data posture: synthetic data only
- Production launch: not authorized

## Local verification

```bash
npm install
npm run lint
npm run build
```

The `/api/health` endpoint reports whether the application process is running.
